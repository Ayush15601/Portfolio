# Portfolio Website | Ayush Tewari

A modern, responsive personal portfolio built to showcase my projects and skills as a Frontend Developer. 

## Live Demo
[**View the live site here**]([https://github.io](https://ayush15601.github.io/Portfolio/)

## Features
- **Responsive Design:** Fully fluid layout using media queries for mobile, tablet, and desktop.
- **Dark/Light Mode:** Seamless theme switching for better user experience.
- **Interactive UI:** Typing animations, hover effects, and smooth scroll navigation.
- **Contact Form:** Fully functional contact section integrated with Formspree.

## Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, Grid, and `clamp()` for fluid typography.
- **JavaScript (ES6+):** Scroll animations and mobile menu logic.

## 📂 Project Structure
```text
├── assets/          # Images, icons, and favicon
├── index.html       # Main structure
├── style.css        # Custom styles
├── script.js        # Interactivity logic
└── cv.pdf           # Downloadable resume
```
